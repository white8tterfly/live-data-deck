# 弹幕墙 · B 站直播弹幕录制器

多房间挂机录制 B 站直播弹幕的本地工具：实时 Web 管理界面、自动重连与节点轮换、
懒落盘、隐私脱敏、房管处置弱标签回捞。Python 异步核心 + FastAPI + 原生 Web UI，
**零前端构建步骤**，开箱即用。

## 功能特性

- **多房间同时录制**：开播自动连接、下播立即断线释放账号并发名额；未开播不占连接（45s 轮询）
- **生产级连接策略**（实战实测）：
  - wbi 签名获取 danmu token，边缘节点 host_list 自动轮换
  - 秒踢指数退避 + 随机抖动，全部节点失败自动熔断冷却，避免触发账号风控
  - `-352` 风控自动重建浏览器指纹与签名密钥
  - 浏览器同款握手头（UA / Origin / Cookie），应用层 25s 心跳
- **懒落盘**：只有真实开播（`live_status==1`）才创建文件；未开播 / 轮播内容直接丢弃
- **消息类型**：普通弹幕、醒目留言（SC）、礼物（默认关闭）、开播 / 下播事件
- **噪声过滤**：纯大表情弹幕自动过滤（`妈妈[抓狂]` 这类文字 + 表情保留）
- **隐私保护**：uid 哈希匿名（sha256 加盐）、用户名掩码、链接 / @用户 / QQ / UID / 手机号自动脱敏
- **房管处置弱标签**：房管拉黑 / 禁言时，自动回捞被处置者近 30 分钟弹幕 + 事件前 20 条语境
- **全部关播 N 分钟自动停止**，支持错峰启动避免同秒握手
- **简洁 Web UI**：仪表盘、实时弹幕流、房间管理、录制文件浏览 / 预览 / 下载、运行日志、设置
- **命令行模式**：无界面挂机 / 临时单房间录制同样支持

## 快速开始

需要 Python 3.10+。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动（自动打开浏览器 http://127.0.0.1:8787）
python run.py
#   指定端口 / 不自动开浏览器：
python run.py --port 9000 --no-browser
```

首次使用：

1. 打开「**设置**」页，粘贴 `SESSDATA`（推荐，游客模式可留空但容易被边缘节点秒踢）：
   浏览器登录 <https://live.bilibili.com> → F12 → Application → Cookies → 复制 `SESSDATA`
2. 在「**房间管理**」添加直播间号（直播间 URL 里的数字）和保存目录名，添加后自动开始录制
3. 在「**仪表盘**」查看连接状态，「**实时弹幕**」查看实时流

> SESSDATA 只保存在本机 `config/settings.json`（已被 .gitignore 排除），不会上传到任何第三方。

### 命令行模式

```bash
# 按 config/targets.json 录制（可从 config/targets.example.json 复制改）
python -m recorder.cli

# 临时录制单个房间
python -m recorder.cli --room 22637261

# 录 1 小时后退出
python -m recorder.cli --duration 3600

# 全部房间关播 60 分钟后自动停止
python -m recorder.cli --idle-stop 60

# 同时录制礼物事件
python -m recorder.cli --keep-gifts
```

也可以使用 `.env` 文件配置凭证（见 `.env.example`），环境变量优先级高于设置页。

## Web 界面

| 页面 | 功能 |
| --- | --- |
| 仪表盘 | 在录房间 / WS 连接 / 弹幕总数 / 实时速率统计；房间卡片（状态徽章、标题、节点、重连次数、分类计数、单房间启停） |
| 实时弹幕 | WebSocket 实时推送，按房间 / 类型过滤，SC / 礼物 / 房管处置分色展示，支持暂停滚动 |
| 房间管理 | 添加 / 删除目标、启用开关、单个开始 / 停止，动态生效无需重启 |
| 录制文件 | 按主播目录浏览 jsonl，在线预览（JSON 美化）与下载 |
| 运行日志 | 连接、风控、熔断、房管处置等事件实时日志，按级别过滤 |
| 设置 | SESSDATA 与登录态检测、匿名盐、数据目录、录制开关、轮询与空闲停止参数 |

## 数据格式

```
data/
├── records/{主播目录}/live_YYYYMMDD.jsonl      # 弹幕 / SC / 礼物
└── weak_label/{主播目录}/weak_YYYYMMDD.jsonl   # 房管处置弱标签
```

每行一个 JSON 对象：

- 文件首行 `session_header`：房间号、主播、标题、采集时间
- `danmaku`：`text` / `uid_anon` / `uname_anon` / `medal`（粉丝牌名+等级）/ `ts` / `mode`
- `super_chat`：额外含 `price_rmb`
- `moderation_event`：房管拉黑 / 禁言事件、`suspect_danmaku`（被处置者弹幕）、
  `context_before`（语境）。**弱标签不是金标准**（可能误封、可能是广告剧透），使用前需人工判断

## 协议与稳定性说明

- 单账号同时挂多个**在播**房间存在并发上限（实测约 3–4 个），超出的连接会被 0s 踢断。
  本工具的策略是「未开播不持有 WS + 下播立即断线 + 全节点失败熔断」，把连接数压到当前在播数；
  若同时在播长期超过上限仍被踢，请减少同时录制数或改用多账号。
- B 站接口与风控策略可能随时调整；连接逻辑基于 2026-09 实测验证。
