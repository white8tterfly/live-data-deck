============================================================
 直播数据舱 Live Data Deck v1.5.1  ·  Windows 绿色版使用说明
 B站直播全数据录制与分析平台（弹幕 / 人气 / 营收 / 战报 / 视频 / AI 高能解读）
============================================================

【这是什么】
一个本地运行的小工具：挂机录制 B 站直播间的弹幕、SC、礼物营收、
观看人气曲线，并能一键生成单场直播 PNG 战报、做多场数据分析。
新版还提供两个默认关闭的附加能力：直播视频直录（FLV，可自动找出
高能时刻并一键切片）和 AI 高能解读（让 AI 帮你写切片标题与文案）。
无需安装 Python，解压即用。仅支持 Windows 10/11 64 位。

------------------------------------------------------------
【第一步：解压】
------------------------------------------------------------
1. 把整个压缩包解压到任意目录（建议路径不要带特殊符号），
   例如 D:\LiveDataDeck\
2. 不要只把 LiveDataDeck.exe 单独拖出来——它必须和旁边的
   _internal 文件夹放在一起才能运行。

------------------------------------------------------------
【第二步：启动】
------------------------------------------------------------
双击  LiveDataDeck.exe
会弹出一个黑色控制台窗口（请勿关闭，关闭=停止录制），
约 1 秒后浏览器自动打开 http://127.0.0.1:8787

如浏览器没自动开，手动在浏览器地址栏输入上面的地址即可。
想停止程序：在黑窗口按 Ctrl+C，或直接关闭该窗口。

------------------------------------------------------------
【第三步：首次配置（只需一次）】
------------------------------------------------------------
1. 登录凭证（强烈建议配置，否则容易掉线）：
   - 浏览器登录 https://live.bilibili.com
   - 按 F12 打开开发者工具 → Application（应用）
   - 左侧 Cookies → 点 https://live.bilibili.com
   - 找到 SESSDATA，复制它的值
   - 回到本工具「设置」页，粘贴 SESSDATA 并保存
   （SESSDATA 只保存在你本机的 config 文件夹里，不会上传）

2. 打开「录制礼物事件」开关：
   在「设置」页打开，否则战报里没有金礼物营收。

3. 添加直播间：
   进入「房间管理」→ 填写房间号（直播间网址里的那串数字）
   和保存目录名（建议填主播名）→ 保存。
   主播开播即自动开始录制，下播自动断线，无需值守。

------------------------------------------------------------
【日常怎么用】
------------------------------------------------------------
· 仪表盘：看录制状态、实时人气与峰值
· 实时弹幕：看当前直播弹幕流
· 录制文件：浏览历史录制
    - 点「战报」→ 弹窗看摘要 → 点「生成 PNG 一页战报」
      图片直接在弹窗内预览，点「下载 PNG」保存，
      也可点「新标签页打开」后右键另存
    - 点「去重」可清理刷屏重复弹幕（生成新文件，不影响原文件）
· 数据分析：勾选多个直播文件，生成跨场统计报告
· 视频录制：浏览录好的视频场次，点「高能时间轴」查看整场高能
  分布、复制播放器跳转命令，安装 ffmpeg 后还能一键切出片段
· 设置：可切换日间 / 夜间主题；「战报样式」可自定义配色、
  字体、排版与内容区块，支持即时预览，保存后生成战报即生效
  （视频与 AI 的开关也在设置页，见下一节）

------------------------------------------------------------
【视频录制与 AI 高能解读（可选，默认关闭）】
------------------------------------------------------------
两个功能都不影响弹幕录制，按需开启：

· 录视频（两个开关都要开）：
  1. 「设置」→「启用视频直录（全局总开关）」打开
     （只对开启后新启动的录制任务生效，正在录的房间先停止
       再开始即可）
  2. 在「房间管理」或房间卡片上勾选「🎥 视频」
     （下一场开播时生效）
· 画质与空间：原画约 1.4–3.6 GB / 小时，游客身份只能录超清，
  填好 SESSDATA 才能录原画；磁盘剩余低于下限时（默认 5GB）
  会自动停止视频并告警，弹幕不受影响。
· 产物：data\video\<主播目录>\ 下的 FLV 视频（断线会自动分段，
  绝不往画面上烧弹幕）、同名 .ass 弹幕字幕（用 VLC/mpv 播放
  可自由开关）和 .meta.json 场次信息。
· 找高能 / 切片段：「视频录制」页点「高能时间轴」，按弹幕密度、
  SC、人气自动标出 Top N 高能段；想直接切出片段，需要自行安装
  ffmpeg 并加入系统 PATH（本工具不内置 ffmpeg），不装也能复制
  VLC/ffplay 跳转命令手动定位。
· AI 高能解读：在「设置」填好 AI 接口（支持 DeepSeek、通义千问、
  Kimi 或本地 Ollama 等 OpenAI 兼容接口），点「测试连接」通过后，
  在高能时间轴弹窗点「🤖 AI 解读本场」即可，也可以开启
  「场次结束后自动解读」。
  A 档轻量便宜（给高能段写标题/封面字/理由），C 档更深更贵
  （整场粗筛补漏 + 写口播开场白），按需要选。
  AI 只会收到弹幕文字、SC 和时间统计，不会收到视频文件、
  UID 或 Cookie；结果缓存在视频旁的 .ai.json 文件里，重复查看
  不重复扣费；API 调用费用由你与服务商结算，文案请自行把关。

------------------------------------------------------------
【数据存在哪】
------------------------------------------------------------
· 录制数据：程序目录下的  data\  文件夹（可在设置页改位置）
  其中 data\records 存弹幕等 jsonl，data\video 存视频与字幕
· 配置文件：程序目录下的  config\  文件夹
  （含你的 SESSDATA 和 AI 的 API Key，请勿外传；换电脑时拷贝
   config 和 data 即可完整迁移）

------------------------------------------------------------
【团队共享一个实例（推荐）】
------------------------------------------------------------
团队只需一台常开的电脑运行本程序：
  1. 在程序目录地址栏输入 cmd 回车，执行：
       LiveDataDeck.exe --host 0.0.0.0 --no-browser
  2. 查这台电脑的局域网 IP（设置 → 网络 → 属性，如 192.168.1.20）
  3. 同一网络的同事浏览器访问  http://192.168.1.20:8787
不要多台电脑用同一个 SESSDATA 同时录制，会互相挤掉线。

【常见问题】
------------------------------------------------------------
Q：双击 exe 没反应 / 提示缺少 dll？
A：确认整个文件夹（含 _internal）一起解压了；杀软可能误报，
   可将程序目录加入信任区后重试。

Q：端口 8787 被占用？
A：用命令行启动并换端口：LiveDataDeck.exe --port 9000

Q：战报「观看人气曲线」显示无数据？
A：人气采集是 2026-10 新版才有的，更早的历史文件没有该数据，
   其余指标正常，新录制的直播会自动带上曲线。

Q：总营收怎么算的？
A：SC 金额 + 金礼物（金瓜子 ÷ 1000）；免费的银瓜子礼物不计。

Q：开了视频开关，开播后却没有视频文件？
A：全局开关只对开启之后新启动的录制任务生效——到房间卡片先
   「停止」再「开始」；另外还要在该房间勾选「🎥 视频」
   （下一场开播生效）。

Q：视频只能录超清、录不到原画？
A：没填 SESSDATA 或凭证失效时 B 站只给游客画质，回设置页重新
   填写并检测登录态即可。

Q：「秒切」按钮是灰的 / 提示未检测到 ffmpeg？
A：切片功能需要自行安装 ffmpeg（ffmpeg.org 下载 Windows 版，
   把 bin 目录加入系统 PATH，重启本程序）。不装也不影响录制，
   可复制 VLC/ffplay 跳转命令手动定位高能时刻。

Q：AI 解读连不上 / 报错？
A：先在设置页点「测试连接」，检查接口地址、API Key 和模型名；
   用本地 Ollama 的话要先 ollama pull 好模型并保持其运行。

Q：升级新版？
A：下载新压缩包解压到新目录，把旧目录的 config\ 和 data\
   两个文件夹拷过去即可。
