SESSDATA 有什么用？不填会怎样？
  • 不填也能正常录制：弹幕、SC、进场消息、人气等属于直播间的公开广播，游客身份就能接收，和你不登录 B 站也能看直播弹幕一样；
  • 填写后连接更稳：带登录态时边缘 WS 节点更少被风控秒断，长时间挂机更可靠；
  • 战报数据更全：金礼物、大航海等需要登录态的营收明细才拿得到，否则战报营收可能偏少；
  • 解锁关注导入：「房间管理 → 从 B 站关注导入」可读取关注列表、查看哪些主播正在开播并一键加入录制（该接口游客无权访问）。
如何获取 SESSDATA（约 30 秒）
  1. 用电脑浏览器（Chrome / Edge）登录 live.bilibili.com
  2. 按 F12 打开开发者工具，切到 Application（应用）→ 左侧 Cookies → https://live.bilibili.com
  3. 在 Cookie 列表找到 SESSDATA，复制它的值，粘贴到上方输入框并保存
凭证仅保存在本机 config/settings.json，不会上传任何服务器；在 B 站退出登录或改密会使其失效，重新复制一次即可。
录制时用它把观众真实 UID 加盐哈希成 16 位匿名 ID，文件中不保存真实 UID，用于隐私保护。 盐值相同，同一观众在各场次的匿名 ID 才一致，跨文件去重/用户聚合才能对上； 一旦更换盐值，历史文件里的旧匿名 ID 与新数据将无法关联（跨场去重、按匿名 ID 添加的关心名单会失效，真实 UID 不受影响）。 无特殊需求保持默认即可，也可用环境变量 DANMAKU_ANON_SALT 覆盖。
